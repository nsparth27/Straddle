Welcome to the Dhan Straddle Pro Web Application!

🚀 QUICK START (FOR NEW USERS):
------------------------------------------------------------------------
1. Double-click "start_app.bat".
2. The batch script will automatically verify dependencies, start the
   server in the CMD window, and open http://localhost:3000 in your browser.
3. If Node.js is missing, the launcher will guide you to download it.

⚙️ FIRST TIME CONFIGURATION (INSIDE THE WEB APP):
------------------------------------------------------------------------
1. Go to the Settings tab [ F3 ] in your web browser.
2. Enter your Dhan Client ID and 24-hr Access Token.
3. Enter your Telegram Bot Token & Chat ID.
4. Click "Save Settings".
5. Toggle Telegram Alerts ON when ready to receive live breakout alerts!

📁 DISTRIBUTION CONTENTS:
------------------------------------------------------------------------
- start_app.bat         : Automated 1-click launcher.
- server.js             : Core Node.js Web & Straddle Data Engine.
- config.json           : Settings & 230 F&O Watchlist Store.
- public/index.html     : Bloomberg Terminal Web Dashboard UI.
- public/style.css      : Bloomberg Terminal dark theme styles.
- public/app.js         : Real-time reactive chart & dashboard logic.
- straddle_alert.py     : Standalone Python Straddle Scanner.
- test_connection.py    : Diagnostic connection test (Python).
- test_connection.js    : Diagnostic connection test (Node.js).
