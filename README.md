# Dhan Straddle Pro — Bloomberg Terminal & Real-Time Breakout Engine

Real-time F&O and MCX Commodity ATM Straddle Breakout Engine with automated Previous Day High (PDH) tracking and Telegram notification dispatch.

## 🚀 Live Cloud Deployment (Render.com)

1. Connect this repository on [Render.com](https://render.com) as a **Web Service**.
2. **Build Command:** `npm install`
3. **Start Command:** `node server.js`
4. **Plan:** Free ($0)

### ⏱️ Keep-Alive (24x7 Continuous Execution):
Ping `https://<your-render-url>/api/status` every 5 minutes on [cron-job.org](https://cron-job.org) or [UptimeRobot](https://uptimerobot.com).

## 💻 Local Quickstart

```bash
npm install
npm start
```
Terminal interface: [http://localhost:3000](http://localhost:3000)
